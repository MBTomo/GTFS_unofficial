# GTFS_unofficial

Googleマップの経路検索に対応していないバス路線について、公開されている時刻表や運行情報等をもとに非公式のGTFSデータを作成・公開しています。

作成には「見える化共通入力フォーマット・GTFS」を活用しています。
(https://www.gtfs.site/)
